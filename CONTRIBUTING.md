# Contributing

This project is **proprietary and All Rights Reserved** (see [LICENSE](LICENSE)).

The source is published for transparency and review only. It is **not** open
source, and the project is **not accepting external contributions** — please do
not open pull requests. They will not be reviewed or merged.

## Security issues

If you've found a security vulnerability, **do not** open a public issue.
See [SECURITY.md](SECURITY.md) for responsible-disclosure instructions.
