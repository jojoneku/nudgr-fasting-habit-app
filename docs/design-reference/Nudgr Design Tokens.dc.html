Usage notes
Accent colors with rgba() tinted backgrounds use the same hue at .10–.16 opacity. Ring track colors (the dark fill behind each ring arc) are tinted dark on dark mode and tinted light on light mode. The --fast-light, --move-light, and --danger-light values serve as on-dark text variants — they are replaced with deeper values in light mode for sufficient contrast.
