Forms and dialogs

One form language for all 17 dialogs: a 520px dialog with a 24px radius, uppercase labels above the fields, 46px inputs, one primary button on the right, Cancel beside it, and a destructive action alone on the left. Optional fields sit under a "More options" fold, so the first view shows only what a quick entry needs. Each dialog says where it opens from and where it leads.
